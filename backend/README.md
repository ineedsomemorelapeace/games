# CarsonGames backend

This service serves the static site and provides the Node/PostgreSQL API used by the GitHub Pages frontend.

Authentication uses username and password. The database keeps an internal email-shaped identifier for compatibility with the existing schema; it is generated by the backend and is not supplied by or shown to users.

On Heroku, add Heroku Postgres and set `JWT_SECRET` to a long random value. Initialize the database once with `schema.sql`, then deploy from the repository root. The `DATABASE_URL` and `PORT` values are supplied by Heroku.
